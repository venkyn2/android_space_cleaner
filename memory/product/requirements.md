# Requirements: Phone Cleaner

## Core Value
Build a mobile app that cleans my mobile drive space.

## Personas & Roles
Android users. Public release; friends and family.

## Features
- Find duplicate photos and files
- Find large files and delete them
- Smart AI helper that suggests what to delete
- Have a preview mode before deleting

## Next round (user's words)
"want it to be free with no Add and ensure that any loss i am not responsible" - free, no ads, and a disclaimer/consent that the developer is not responsible for any loss.

## Integrations
- AI text suggestions: Claude Sonnet 5.5 via Emergent universal key

## UI/UX Rules
Expo mobile app, Android.
